# 3. Вантажно-пасажирський

Практичне рішення «2 в 1» для одночасного перевезення людей і вантажів.

## У комплектацію входить
- шумоізоляція;
- обшивка підлоги, боковин, стелі та дверей фанерою;
- застилання підлоги фанерою та автоліном;
- обшивка стелі, боковин і задніх дверей тканиною або екошкірою;
- встановлення пасажирських сидінь із ременями безпеки;
- встановлення освітлення.

## Матеріали папки
- `photos/` — фото робіт цього типу переобладнання (до / після, процес, готовий салон).
